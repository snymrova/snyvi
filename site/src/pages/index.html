Agents make it easy to start. snyvi helps you finish.

One desk for each project

A project's folder with up to four agents in it, side by side: Claude Code, Codex, Gemini, any shell. Each panel says whether its agent is working, done, or waiting on you.

{{clip:desk|Switching from the atlas desk to ledger, where two Claude Code sessions work side by side, one working and one done}}

Nothing scrolls away

Every plan and review an agent writes lands on its desk as a clean page, filed under its project, every version kept. c shows what changed.

{{clip:plan|A plan Claude wrote, opened from the desk's rail as a clean page, filed under its project}}

Out of your head

Each desk keeps its own notes. The agents read them, say how far they've got, and tick one off with the commit it went into. When one needs a decision from you, it asks in the desk's corner and waits.

{{clip:notes|A desk's notes beside its panel: a new one typed in, under one the agent has already ticked off}}

Just as you left it

Switch projects and each desk is exactly as you left it; the agents you walked away from keep working. Home shows where every project was left, and ⌘K searches everything any agent ever sent.

{{clip:home|Home: where ledger was left and its open notes; pressing it opens the desk just as it was}}

Questions

{{icon:chev}}Is it free?

Yes, and open source under the MIT licence. There is no paid tier.

{{icon:chev}}Which agents?

Claude Code, connected from the window on first run. Codex, Cursor, Gemini, Windsurf, VS Code, Zed and Claude Desktop with one line each: snyvi init codex. Any shell in a panel.

{{icon:chev}}Does it work on a Mac?

Yes: the Mac build is signed and notarized, and brew install --cask snymrova/snyvi/snyvi is the way in. We don't own a Mac, so we'd love to hear how your first minute went, on GitHub.

{{icon:chev}}Windows says it "protected your PC".

The Windows installer isn't signed yet, so SmartScreen asks once: More info, then Run anyway. Scoop installs without the prompt, and winget will once Microsoft's review is through. What will be signed, and how.

Install snyvi

Free, MIT, and on GitHub. Your first five minutes:

  1. A desk for a project. It asks what you're working on. That folder becomes a desk, with Claude Code ready in its first panel.
  2. Claude's first page. Ask for a plan. It lands on the desk as a page you can read, not in the scrollback.
  3. Your answer to Claude. Read it, and answer in the panel beside it. That's the loop.
  4. Back another day. The desk is just as you left it, with the plan, the notes and where it stopped.
