Install snyvi

One line for your machine. Then open snyvi from your apps, or run snyvi app. It asks what you're working on, makes that project's first desk, and connects Claude Code from the window. From then on it updates itself, once a day, when you're not looking.

{{install}}

macOS

brew install --cask snymrova/snyvi/snyvi

The app is signed and notarized. Without Homebrew, the one-liner below puts snyvi.app in Applications and snyvi on your PATH.

Linux

curl -fsSL https://snyvi.com/install.sh | sh

It installs into your home, with no root: snyvi into ~/.local/bin, the window beside it when the machine has a display and WebKitGTK 4.1, and a menu entry, the icon and snyvi:// links. Every download is checked against the .sha256 published beside it, and Claude Code is connected if it's installed. Read the script first; snyvi.com/install.sh is a redirect to that file on GitHub.

sh install.sh --deb              # the two .debs instead (Debian, Ubuntu; needs root)
sh install.sh --no-app           # without the window
sh install.sh --no-init          # without registering with Claude Code
sh install.sh --version 1.33.0   # a particular release

The same flags go after sh -s -- when piping from curl.

Windows

scoop bucket add snyvi https://github.com/snymrova/scoop-snyvi
scoop install snyvi

Or the installer. It isn't signed yet, so SmartScreen asks once: More info, then Run anyway. Scoop installs without the prompt. snyvi is in Microsoft's review for winget, and winget install snymrova.snyvi works once it's through.

Signing is on its way: free code signing provided by SignPath.io, certificate by SignPath Foundation. The code signing policy says what will be signed, and how.

Cargo

cargo install snyvi
snyvi init-claude --auto

That builds the daemon, the CLI, the MCP server and the hook from crates.io: everything but the window, which links a browser engine. snyvi app then opens snyvi in your browser instead.

Check what you downloaded

Every release file carries a .sha256 beside it and a build attestation. This proves a file came out of the release workflow in snyvi's repository, on the commit its tag names:

gh attestation verify <file> --repo snymrova/snyvi

Then

Open snyvi. It asks What are you working on?, and the folder you pick becomes your first desk. Every other agent is one line: snyvi init codex, or cursor, claude-desktop, gemini, windsurf, vscode, zed. The guide has the rest.

Updating

snyvi checks for a new version every six hours or so and applies one at most once a day, at a quiet moment, after checking its signature. snyvi update off stops the checks; snyvi update still works when you ask. A .deb is owned by root and a cargo build by you, so for those snyvi only says a new version is out.
